Engineering references
----------------------

The engine design is based on published source and on inspecting a shipped WebView
browser. No source code was copied from either project:

  Brave adblock-rust (MPL-2.0)
    https://github.com/brave/adblock-rust
    Token-bucket rule indexing, frequency-aware token selection, cosmetic class/id
    lookup, scriptlet resource model, serialized filter lists.

  DuckDuckGo Privacy Browser for Android (Apache-2.0)
    https://github.com/duckduckgo/Android
    WebView request interception pipeline, empty-response blocking, tracker
    allowlists and same-entity bypass, surrogate scripts, popup/redirect handling.

NovelSpeak itself is not affiliated with Brave, DuckDuckGo, EasyList, or uBlock Origin.
