## E. What the matrix says

- Table stakes at the top of the market: read-along highlight, library/sync, media controls, a credible background-playback story. Missing these makes a reader feel like a demo.
- Rare and therefore differentiating: free offline neural voices (Kokoro/Pocket), generic web extraction with auto-next-chapter, and no-account/no-meter operation.
- Documented screen-off playback is not universal, and several paid apps have reviews complaining it fails; in-process playback is a defensible reliability story.
- File formats are where free incumbents win (ReadEra, PocketBook, Moon+). Add share-sheet/URL ingestion first; EPUB later because it is the expensive one.
