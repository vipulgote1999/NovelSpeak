# NovelSpeak 1.0.0

NovelSpeak is an Android browser that reads web pages aloud — built because Chrome's
"Listen to this page" fails on novel sites and stops when the screen locks.

## Highlights

- **Any URL** — a full WebView browser with URL bar, back/forward, reload, and next-chapter
  navigation.
- **Generic extraction** — Mozilla Readability plus a text-density fallback, tuned for
  serialized-novel sites. The spoken paragraph is highlighted and auto-scrolled on the page.
- **Two TTS engines** — Android system TTS (instant, offline, device languages) or
  sherpa-onnx neural voices:
  - Kokoro int8 — 11 English voices, 103 MB.
  - Pocket TTS int8 — zero-shot voice cloning from a reference clip, 98 MB.
- **Screen-off playback** — a media-playback foreground service, wake lock, and MediaSession
  controls keep audio running when the screen locks.
- **Streaming pipeline** — sentences are split ahead of time and the next ones are synthesized
  while the current sentence plays.
- **Ad blocking** — EasyList/EasyPrivacy/uBlock rules, cosmetic filtering, popup/redirect
  blocking, per-site bypass, list updates, and a built-in self-test.

## Fixed in this release

- Neural TTS no longer cuts off after the first 1.2 s chunk.
- Duplicate page-load events for the same URL no longer rewind playback.
- Same-URL reloads reinstall the extractor correctly.
- Extraction noise, reader rewind, TTS truncation, media focus, and transport-control fixes
  from on-device testing.

## Install

1. Download `NovelSpeak-1.0.0-arm64-v8a.apk` from this release.
2. Optionally verify it against `NovelSpeak-1.0.0-arm64-v8a.apk.sha256`.
3. Open the APK on the device and allow installation from this source if prompted.

Requirements: Android 7.0 (API 24) or newer, arm64-v8a device.

**Upgrading from a debug build:** this is the first release and it is signed with a new release
key. Android will refuse to install it over a debug-signed build. Uninstall the old build first;
that erases its settings and any downloaded neural models.

On first run, grant the notification permission so the playback notification can appear.

## Known limits

- Cloudflare-protected sites may show a challenge inside the WebView; solve it once and the
  session persists.
- Pause resumes at the start of the current sentence.
- Neural model downloads are 98–103 MB; use Wi-Fi and keep the app open during extraction.
- The APK is arm64-v8a only. See the README to build another ABI.
