# NovelSpeak 1.1.0

NovelSpeak is an Android browser that reads web pages aloud — built because Chrome's
"Listen to this page" fails on novel sites and stops when the screen locks.

## Highlights

- **Auto mode** — turn it on in Settings → Reading and pages read themselves: the chapter is
  extracted and spoken on load, and when it ends the app shows "Chapter finished — next page in
  3 s", opens the next chapter, waits 2.5 s and continues. Off by default.
- **Generation ahead of playback** — synthesis now keeps roughly 12 seconds of audio buffered
  (up to 8 sentences) while the current sentence plays, so sentence changes no longer wait for
  the model. The system engine renders to PCM in-process too.
- **Cleaner audio** — a low-level noise gate removes vocoder hash between words, sentence tails
  fade to silence instead of clicking, and output gain no longer steps between chunks. Measured
  noise floor: −51.6 → −80.3 dBFS with speech level unchanged.
- **Headset/Bluetooth controls** — play/pause, next and previous now work on the system engine
  as well as the neural engine, including with the screen off and after playback was stopped.
- **Reader mode everywhere** — dark surfaces are enforced on any site, tables use real table
  layout instead of `display:flex`, site banners/notices are hidden, and wide media scrolls
  instead of clipping. Reader mode also stays on when a page yields no text.
- **TTS text safety** — quotes, unbalanced dialogue shells, asterisks, censored words, ellipses
  and dotted obfuscation (`s.h.i.+ning`) are normalized before Kokoro/Pocket; punctuation-only
  fragments are skipped and short dialogue fragments are merged, so the model never receives
  degenerate input.

## Fixed

- Neural TTS hallucinating or producing continuous noise on quotes and special characters.
- Little background noise and boundary clicks in TTS output.
- Headset media buttons doing nothing (or not resuming) with the system TTS engine.
- Playback stalling after a seek while a long sentence was generating.
- The page being parsed and sentence-split up to three times per load.
- Chapter title staying on the previous chapter after an automatic advance.
- Seek bar thumb not following the sentence position after a chapter append, and its missing
  accessibility value.
- Model deletion happening without confirmation.

## Install

1. Download `NovelSpeak-1.1.0-arm64-v8a.apk` from this release.
2. Optionally verify it against `NovelSpeak-1.1.0-arm64-v8a.apk.sha256`.
3. Open the APK on the device and allow installation from this source if prompted.

Requirements: Android 7.0 (API 24) or newer, arm64-v8a device.

**Upgrading from 1.0.0:** this build uses the same release key, so it installs as an update.
Settings and downloaded neural models are preserved.

On first run, grant the notification permission so the playback notification can appear.

## Known limits

- Cloudflare-protected sites may show a challenge inside the WebView; solve it once and the
  session persists. Auto mode skips challenged pages instead of reading them.
- Pause resumes at the start of the current sentence.
- A seek cannot interrupt the native vocoder mid-call; the stale audio is discarded and the new
  sentence starts as soon as that call returns.
- Neural model downloads are 98–103 MB; use Wi-Fi and keep the app open during extraction.
- The APK is arm64-v8a only. See the README to build another ABI.
