# NovelSpeak 1.2.0

NovelSpeak is an offline-first Android reader for web novels: it extracts a page, reads it
aloud with system or neural voices, keeps playing with the screen off, and remembers where you
stopped — with no account, no ads and no analytics.

## Highlights

- **Home tab** — opening the app lands on a quiet start page with the NovelSpeak wordmark, one
  search field, a curated shortcut grid for novel sites (and Library), and Continue-reading
  cards. No feed, no personalization profile.
- **Categorized settings** — Reading aloud, Voices & previews, Playback & sleep,
  Reading & display, Privacy & data, Advanced and About, each a short page with a live summary
  instead of one long scroll.
- **On-device voice previews** — audition every installed Kokoro speaker (11) and the Pocket
  narrator with a ▶, even while system TTS is selected. Previews pause/resume the reader, load
  the auditioned model, then restore your active model and selected voice.
- **Voice-aware player** — the player card shows the voice actually in use, and voice/engine
  changes apply on the next Play instead of after a restart.
- **Reliable transport** — Read always restarts the current page from sentence 1 (auto mode,
  paused, mid-extraction and verification pages included); Next ch validates the prefetched
  chapter, installs page scripts on demand, retries while loading, and falls back to a numbered
  URL when no anchor exists.
- **Durable imports** — EPUB/PDF/text imports are extracted into app-private storage, appear in
  Library → Imported books and Home → Continue reading, reopen for TTS, and save progress.
- **Library & reading** — saved positions, bookmarks, reading stats, share/selected-text intake,
  chapter prefetch, typography controls, word-level read-along, sleep timer, WAV capture of live
  playback, two-pane layout on wide screens.
- **Privacy by design** — five permissions, no analytics or ad SDKs, cleartext restricted to
  loopback test hosts, backups disabled, signed model catalog with explicit OTA checks.

## Fixed since 1.1.0

- EPub imports failing silently on some Android parsers (namespace-aware fallback added).
- Imported books disappearing after leaving the reader; they are now stored and indexed.
- Read doing nothing in auto mode / on verification pages; it now explicitly cancels
  auto-advance, re-extracts, restarts at sentence 1 or reloads once when blocked.
- Next ch reopening the same chapter after a stale prefetch, and failing when pressed before
  extraction finished.
- Settings footer covering the last card; reset moved to Advanced and status is inline.
- Voice changes requiring a process restart; the cached engine is now invalidated.
- Bookmark flow and library sections hidden below a longer library list (regression tests now
  scroll to the section).

## Install

1. Download `NovelSpeak-1.2.0-arm64-v8a.apk`.
2. Optionally verify it with `NovelSpeak-1.2.0-arm64-v8a.apk.sha256`.
3. Open the APK on the device and allow installation from this source if prompted.

Requirements: Android 7.0 (API 24) or newer, arm64-v8a.

**Upgrading:** this build uses the same release key as 1.1.0, so it installs as an update and
keeps settings, library entries, imported books and downloaded neural models.

## Known limits

- PDF import is text-layer only (no OCR); scanned PDFs will not import.
- EPUB import does not bypass DRM.
- Neural voice previews need the matching model installed; low-memory devices may refuse a
  preview instead of risking a native crash.
- Cloudflare-protected sites may require solving a challenge once inside the WebView.
- The APK is arm64-v8a only; the neural libraries dominate its size.
