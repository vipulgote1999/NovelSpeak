# NovelSpeak 1.2.1

A small patch for the "one sentence spoken twice" bug reported after 1.2.0.

## Fixed

When a chapter was prefetched and **Next ch** was pressed near the end of the current chapter,
the first sentences of the next chapter were generated twice: the app appended the cached
chapter while audio was still playing (starting generation once), then seeked to the new chapter
start and generated them again. The reader now stops the current playback before appending the
prefetched chapter, so those sentences are synthesized and played exactly once.

Everything else is unchanged from 1.2.0 (home tab, categorized settings, durable imports,
on-device voice previews, voice-aware player, Read restart and reliable Next ch).

## Install

1. Download `NovelSpeak-1.2.1-arm64-v8a.apk`.
2. Optionally verify it with `NovelSpeak-1.2.1-arm64-v8a.apk.sha256`.
3. Open the APK on the device and allow installation from this source if prompted.

Requirements: Android 7.0 (API 24) or newer, arm64-v8a.

**Upgrading:** same release key as 1.2.0; installs as an update and keeps settings, library,
imported books and downloaded models.
