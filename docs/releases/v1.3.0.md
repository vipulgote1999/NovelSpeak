# NovelSpeak 1.3.0

NovelSpeak is an offline-first Android reader for web novels: it extracts a page, reads it
aloud with system or neural voices, keeps playing with the screen off, and remembers where you
stopped — with no account, no ads and no analytics.

## Highlights

- **Two new neural voice families** — **Supertonic 3** adds two curated fast styles (F1 female,
  M1 male; 20 ship upstream) in a 123 MB int8 model, and is the preferred default once installed.
  **ZipVoice** adds zero-shot cloning driven by a reference clip plus its verbatim transcript
  (zh + en; 104 MB int8 plus the 52 MB 24 kHz vocoder). Kokoro and Pocket TTS remain available.
- **Faster first audio** — the selected neural engine is prewarmed when content is queued and up
  to 8 s / 4 sentences are prerendered while playback is held. Play starts as soon as the first
  PCM arrives, with no model reload and no short→long sentence gap.
- **Playback that survives interruptions** — pause, calls and screen changes no longer leave TTS
  silent or stuck. Short `AudioTrack` writes abort only the current chunk, the writer thread is
  self-healing, transient audio-focus loss resumes when the call ends, and a pause during
  "Preparing audio…" cancels the pending preroll.
- **Ad text stays out of the reader** — extraction drops a block when its only live match is
  hidden by a cosmetic rule, so hidden ad paragraphs are no longer spoken by either engine.
  Extraction now waits for the cold-start filter engine and applies the first cosmetic batch
  synchronously.
- **Ad blocking before the page runs** — AndroidX WebKit is vendored for document-start
  injection: a popup guard runs before page scripts in both the visible and prefetch WebViews,
  the prefetched chapter gets the full network/cosmetic/behavioural pipeline, procedural
  operators such as `:has-text` and `:matches-css` are supported, and a bundled local
  supplement covers first-party popunders and ad slots that upstream lists miss.
- **On-device TTS benchmark** — a debug-gated activity measures every installed neural engine
  and system TTS in a fresh process (cold load, first audio, synthesis time, RTF, peak/RMS and
  RSS). Emulator and iQOO I2214 results are committed in
  `docs/benchmarks/2026-11-03-tts-benchmark.md`.

## Fixed since 1.2.1

- Pause, calls and screen changes no longer leave playback silent while the UI says "Playing".
- Transient audio-focus loss resumes automatically; Play waits honestly while a call owns audio.
- Pause during "Preparing audio…" is honored instead of starting playback after the pause.
- System TTS can no longer replay a stale sentence after a quick pause/resume.
- A cold Settings visit no longer clamps a saved 3.0× speed to 2.0×.
- ZipVoice no longer crashes when selected (the bundled eSpeak data is passed to sherpa-onnx).
- Document-start setting changes apply immediately instead of on the next page.

## Install

1. Download `NovelSpeak-1.3.0-arm64-v8a.apk`.
2. Optionally verify it with `NovelSpeak-1.3.0-arm64-v8a.apk.sha256`.
3. Open the APK on the device and allow installation from this source if prompted.

Requirements: Android 7.0 (API 24) or newer, arm64-v8a.

**Upgrading:** this build uses the same release key as 1.2.1, so it installs as an update and
keeps settings, library entries, imported books and downloaded neural models.

## Known limits

- PDF import is text-layer only (no OCR); scanned PDFs will not import.
- EPUB import does not bypass DRM.
- ZipVoice is slower than real time on mid-range devices and needs its 52 MB vocoder; use
  Supertonic, Pocket or Kokoro for long reading sessions.
- Neural voice previews need the matching model installed; low-memory devices may refuse a
  preview instead of risking a native crash.
- Cloudflare-protected sites may require solving a challenge once inside the WebView.
- The APK is arm64-v8a only; the neural libraries dominate its size.
