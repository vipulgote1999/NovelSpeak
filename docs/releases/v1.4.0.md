# NovelSpeak 1.4.0

**Release date:** 7 November 2026
**Version code:** 20
**Package:** `app.novelspeak`
**Play target:** Android 16 (API 36), minSdk 24, arm64-v8a

## What's new

This release is the Play Store readiness release. It keeps the reader and voice features from
1.3.0 and fixes the submission blockers found in the 2026 audit.

- Target API 36 and compile SDK 36 for the Google Play 31 August 2026 requirement.
- Signed Android App Bundle (AAB) build path with 16 KB page-size alignment.
- Original adaptive launcher icon, round icon and 512 px Play icon.
- WebView security hardening and removal of the reflected JavaScript interface.
- No exported benchmark activity in the Play build.
- Download-size confirmation for neural voices and filter-list updates.
- Diagnostics event/crash logs redacted before sharing.
- Release network config blocks all cleartext, including localhost.
- Custom back handling preserved on Android 16 via the documented opt-out.
- Store packet under `docs/play-store/`: listing copy, data safety, content rating,
  foreground-service declaration, review notes and screenshots.

## Known limits

- Cloudflare-protected sites can show a challenge; NovelSpeak detects it, does not read it
  aloud, and does not bypass it.
- Neural voices are optional large downloads (about 50–200 MB) and require confirmation.
- The app is a general-purpose web reader with unrestricted web access; target audience is
  18+ and minor access is restricted on Play.
