# Responsive and accessibility audit — the built pages

Date: 2026-11-25. Scope: all six documents under `site/`. Method: source audit plus the numeric
checks in `tools/site-check.mjs`. **No renderer exists on this machine**, so this file separates what
the source proves from what a person must still look at. Nothing below claims a browser pass.

## 1. Breakpoints

| Width | Layout | What protects it |
|---|---|---|
| 320 | one column everywhere; header is brand + `Menu` (the Download button hides under 520 px); hero text above a 340 px plate cropped to 3:4; buttons full width | `.wrap` gutter 20 px, `overflow-wrap: anywhere` on headings, no fixed-width element anywhere, `.actions` stacks under 480 px, `.models` name/size on one row, `.specs` single column under 560 px |
| 360 | same as 320 with a wider gutter | as above |
| 390 | as 360; hero plate 340 px, read-along sheet padding 24 px | `.readalong` max 34ch, sheet padding `clamp(24px, 5vw, 64px)` |
| 768 (tablet portrait) | hero still one column (split starts at 900); `dock` visible from 720; library figures side by side from 720 | `.hero__grid` single column below 900; `.figures--pair` two columns from 720 |
| 1024 | two-column hero (5/7); footer two columns; FAQ two columns | `.split` two columns from 900, `.closing__grid` two columns from 760 |
| 1440 | content capped at 1200 px, centred; hero 5/7 with the plate at up to 78svh | `.wrap` max-width 1200, `.plate--tall` max-height |
| 1920 | same 1200 px measure with wider margins | `.wrap` max-width |

Vertical rhythm: every section is `min-height: min(88svh, 980px)` with
`padding-block: clamp(72px, 11vh, 132px)`; the hero is `min-height: 100svh`. A section grows with its
content rather than clipping (a deliberate deviation from fixed-height sections; see the contract).

## 2. 200 % text zoom

- All type is `rem`/`clamp()` with `rem` floors; no `px` font sizes.
- No element has a fixed `width`, only `max-width`; `.wrap` is fluid.
- `overflow-wrap: anywhere` on all headings, `.release__links` and the verify command.
- Line lengths are `ch`-based, so larger text re-wraps rather than overflowing.
- The one horizontal-scroll element that existed (`.verify`) was changed to wrap; the page has no
  `nowrap` text and no `overflow-x: auto` region, so nothing needs keyboard access to scroll.

## 5. Keyboard and semantics

- Order: skip link → brand → nav (or `Menu` disclosure) → Download → main → footer.
- `.skip` is the first focusable element, becomes visible on focus, and targets `<main id="main">`.
- The phone menu is a native `<details>`: Enter/Space toggles it, Escape closes it (script) and
  returns focus to `summary`, and every link is a real anchor.
- Focus ring: 2 px with 2 px offset, never transitioned, `--accent` on ink and `--paper-accent` on
  the cream section. `outline: none` is never used.
- Landmarks: one `<header>`, one `<main>`, one `<footer>`, `<nav aria-label="Site">` and
  `<nav aria-label="Footer">`.
- Current page: `aria-current="page"` on the nav and panel link of every subpage (added this pass).
- Headings: one `h1` per page, no skipped levels (checked), section `h2`s, FAQ questions `h3`.
- Images: every `<img>` has `alt`, `width`, `height`; the brand icon is `alt=""` because the wordmark
  follows it; the waveform is `aria-hidden="true"`.
- No form, no dialog, no focus trap, no `tabindex` above 0.
- `lang="en"`, `theme-color`, `color-scheme`, no `user-scalable=no`, no `maximum-scale`.

## 6. Findings fixed in this pass

| Finding | Fix |
|---|---|
| Brand link was 40 px tall | `min-height: 44px` |
| Skip link was ~35 px tall | inline-flex + `min-height: 44px` |
| `.verify` was a `nowrap` scroll region with no keyboard access | wraps with `overflow-wrap: anywhere` |
| Changelog download links were bare inline anchors | `inline-flex` + 44 px |
| Nav had no `aria-current` on any page | added on all four subpages (nav and phone panel) |
| 390 px tablet screenshot was upscaled past its source | capped that figure at 420 px |
| Alt text described things the captures do not show (a cast "roster", a settings "voice list", library "search and filters") | every shipped PNG was opened and every alt rewritten to what is actually in the frame |
| The tablet library capture was a 26-row test-harness dump and the phone library still showed `10.0.2.2`/`localhost` sources plus a "Just a moment…" row | both library images dropped after the independent audit (round 3), along with the library figures; the section keeps its text and specs. The cast and player captures are cropped below the address bar |
| The 2× text capture shows the compact player ellipsising its own labels | removed from the page; the accessibility claims rest on the app's documented 1.3×/2× layouts rather than on a capture that weakens them |
| `.wave.is-paused` had no CSS | `animation-play-state: paused` |
